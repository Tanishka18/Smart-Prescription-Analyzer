# Smart Prescription Analyzer

**Smart Prescription Analyzer** is a web-based healthcare application developed as a university software engineering project to simplify prescription analysis and improve medication safety. The application leverages **Optical Character Recognition (OCR)** to extract medicine names from prescription images and analyzes potential drug-drug interactions using a curated medical database.

By combining image processing with intelligent prescription analysis, the application assists users in identifying possible medication conflicts, promoting safer healthcare decisions and improving accessibility to prescription information.

## Features

* OCR-based prescription text extraction using Tesseract
* Automatic medicine name detection from uploaded prescriptions
* Drug-drug interaction analysis using a medical database
* Prescription image upload and processing
* User authentication with login and signup functionality
* Interactive results page displaying detected medications and interaction warnings
* Web-based interface for easy accessibility
* Cross-origin support for frontend-backend communication
